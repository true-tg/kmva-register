# Єдиний реєстр актів начальника КМВА — голови КМДА

Статичний сайт (HTML/CSS/JS). Публікація: GitHub Pages (Settings → Pages → Branch: main / root).

## Як додати акт
1. Відкрийте `admin/new-act.html` на сайті, заповніть форму, натисніть «Сформувати акт».
2. Завантажте створений файл у `acts/`.
3. Додайте рядок на початок `data/acts.json`. Commit, і сайт оновиться.

## Налаштування
- ПІБ підписанта: замініть `[Ім'я Прізвище]` у `js/editor.js` та `acts/*.html`.
- Фонова клітинка: додайте `img/pattern-grid.png` (необов'язково).
- Увага: GitHub Pages публічний. Для внутрішнього доступу потрібен GitHub Enterprise Cloud або власний сервер.
